# 08 -- Component Reference

One page per major hardware component, written so that someone with none of
this project's history could pick up the rig, understand what each part
does and how it's wired, and repair or rebuild it from scratch.

Each page summarizes the specs that actually matter for this build (in
plain language) and links to the manufacturer's own official documentation
for anything more detailed (full mechanical drawings, absolute maximum
ratings, etc.) rather than reproducing entire datasheets here. Manufacturer
documentation is the authoritative source if anything here ever seems to
disagree with the part in your hand -- component revisions and minor spec
changes happen, so verify against the current official datasheet before a
rebuild, especially for anything dimensional (hole spacing, shaft
diameter).
